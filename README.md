# Festa d'Oro — sitio web

Sitio web estático listo para GitHub Pages.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive.
- `script.js` — menú móvil y animaciones.
- `assets/` — carpeta reservada para fotografías y recursos.

## Importante
El precio se dejó como “Consultar” porque no se proporcionó un precio oficial. Cuando lo tengas, cambia el bloque `price-placeholder` en `index.html`.
